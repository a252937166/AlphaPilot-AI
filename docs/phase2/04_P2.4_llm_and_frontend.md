## P2.4-S3 个股 AI 解读（04 稿"AI解读/投资逻辑/催化剂/风险"） ✅ done 2026-07-22

**models.py**：`StockInsight(symbol pk, generated_at, core_view Text, drivers JSON, model_version, source)`
drivers 元素：`{"text": "...", "tag": "利多|利空|中性", "source_ref": "event:12|score:tech|sector:SH.BK0031"}`。

**services/insight.py::get_or_build(session, symbol, force=False)**：
- 缓存 24h 内直接返回；事件总线该股有新事件则视为过期；
- 输入打包：五维分(StockScore) + 最近 5 事件 + 板块 forecast 行 + 最新预测 horizons + 巨潮档案；
- LLM 输出 schema：`{core_view: str<=120, drivers: [{text<=40, tag, source_ref}]*3..6}`，**要求每条 driver 的 source_ref 必须来自输入清单中给出的 id 列表**（prompt 中明示，收到后校验非法 ref 即丢弃该条）；
- 降级（无 LLM）：规则模板拼 drivers（五维最高/最低维、最近事件、板块状态，各配 tag）——保证页面永远有内容，source 标 "rule"。
**API**：`GET /v1/stocks/{symbol}/insight?force=`。
**验证**：有/无 LLM 两种模式下均返回 3-6 条 drivers 且 tag 枚举合法；二次请求命中缓存（latency <50ms）。

> ⚠ DEVIATION: 原规格把最新预测与巨潮档案列为输入，但示例未定义这两类证据的
> `source_ref`。为避免模型引用不可追溯，白名单扩展为 `forecast:<snapshot_id>` 与
> `profile:<symbol>`；仍要求逐字命中本次输入清单，非法、重复或英文 driver 丢弃，不足 3 条时
> 整组切回规则模式，禁止混合来源冒充纯 LLM 结果。
>
> ⚠ DEVIATION: 真实 `sector_constituents.symbol` 沿用富途 `SH.600519`/`SZ.*` 码，而个股主键
> 为六位数字。S3 查询同时接受三种边界格式并复用规范化校验；板块预测若未与最新
> `SH.000001` 日线同日则不进入解读，避免展示陈旧板块状态。
>
> ⚠ DEVIATION: 真实 `StockScore` 会把缺失因子按中性值映射为 5 分，不能把该持久化分数误当成
> 完整证据。S3 因此同时读取 radar/missing_factors/input_coverage：完全无输入的维度不进入 LLM
> 引用白名单，规则文案明确标“因子输入暂缺”；完全无持久化证据的六位代码也不调用 LLM，
> 仅返回 3 条“暂无有效数据”的中性状态，不填假数字，仍满足页面始终有诚实内容。
>
> ⚠ DEVIATION: SQLite 下两个请求并发首建同一股票时，普通 ORM INSERT 会发生主键竞态。
> 实现增加进程内按 symbol 构建锁与 `INSERT ... ON CONFLICT DO UPDATE`，并用
> `generated_at` 水位阻止慢旧结果覆盖新结果；双 Session 并发回归证明双方成功且最终仅一行。
>
> 验证记录（2026-07-22）：Ruff、strict mypy、418 个 pytest 全绿；S3 的 15 个离线测试覆盖
> 严格 Schema、动态引用白名单、中文校验、稀疏规则降级、24h/模型版本缓存、事件
> `ingested_at` 失效、force、缓存契约自愈、评分输入覆盖、板块前缀、预测并列断点与并发首建；
> 无任何证据的代码返回 3 条中性数据状态且不调用 LLM。隔离无 key 实测返回
> `source=rule`、3 条合法 driver，审计 `not_configured`，二次缓存 1.06ms 且不新增调用；本机
> Qwen 实测返回 `source=llm`、3-6 条合法 driver，审计模型 `qwen3.6-flash`/`ok=1`，连续缓存
> 请求 3.2-12.1ms 且不新增调用。预提交验证产生的 1 行缓存表已重建以应用最终 source 约束并
> 重新生成；受管 API 与 OpenD 均健康，trade proposal/order 仍各 1 条，未触发任何交易调用。
