```python
class SectorForecast(Base):
    __tablename__ = "sector_forecasts"
    __table_args__ = (UniqueConstraint("plate_code", "trade_date", "horizon", name="uq_sector_fc"),)
    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    plate_code: Mapped[str] = mapped_column(String(24), index=True)
    plate_name: Mapped[str] = mapped_column(String(64))
    trade_date: Mapped[date] = mapped_column(Date, index=True)
    horizon: Mapped[int] = mapped_column(Integer)            # 5/10/20 交易日
    score: Mapped[float] = mapped_column(Float)              # 横截面 0-100
    expected_excess: Mapped[float | None] = mapped_column(Float)
    win_rate: Mapped[float | None] = mapped_column(Float)    # 滚动验证回填
    lifecycle: Mapped[str | None] = mapped_column(String(16))  # recovery/rising/boom/decline/bottoming
    rsi14: Mapped[float | None] = mapped_column(Float)
    reversal_score: Mapped[float | None] = mapped_column(Float)
    model_version: Mapped[str] = mapped_column(String(32), default="sector-fc-v1.0.0")
```

**engines/sector_forecast.py**：
1. **板块日频等权指数**：由 sector_constituents × daily_bars 聚合出每板块近 120 日等权收益序列（缓存为进程内 DataFrame）。
2. 特征：mom_5/10/20、宽度（当日上涨占比）、net_inflow_5d（sector_flow_daily 求和）、换手变化、RS（板块20日收益-全市场中位）。
3. `score = rank_pct( 0.35*mom_h + 0.25*flow_z + 0.2*breadth_z + 0.2*rs_z ) * 100`（h 对应 horizon）。
4. **win_rate 滚动验证（必须真实）**：对过去 60 个交易日，每日按当时数据重算 score 取 Top20% 板块，统计其后 h 日等权收益 > 全板块中位的频率 → 该 horizon 的 win_rate（全体 Top 板块统一一个胜率 v1，写进每行）。`expected_excess` = 历史 Top20% 平均超额。
5. 生命周期规则：`score_trend = score_today - score_5d_ago`；boom: score>80 且 rsi14>70；rising: score>60 且 trend>0；decline: trend<0 且 score<60；bottoming: score<30 且 trend≥0；recovery: score 30-60 且 trend>0 且 flow>0。
6. reversal_score = rank_pct( (100-score)*0.4 + flow_turn_z*0.4 + (35-rsi14).clip(0)*0.2 )。

job `sector_forecast`（cron 19:15）对 horizon∈{5,10,20} 各写一批。
**API**：`GET /v1/sectors/forecast?horizon=5` → 排行榜行（含 06 稿所有列）；`GET /v1/sectors/lifecycle`（当前各板块归档）；`GET /v1/sectors/overbought`、`/v1/sectors/reversal`。

**验证**：三 horizon 各 ~90 行；win_rate ∈ (0.3,0.8) 合理区间；生命周期五档均有归属或空档合理；单测：构造 3 板块玩具序列验证 score 排序与 lifecycle 规则。

- breadth_sub = 当日 advancers/(adv+dec) 在近 250 日该比值分布中的分位×100（数据：market_snapshot_agg 每日收盘行——poll job 15:00-15:05 的最后一行即"日行"；不足 250 日按现有天数）；
- limitup_sub = (limit_up - broken_boards) 分位；volume_sub = total_amount 环比分位；volatility_sub = 100 - 指数20日波动分位；
- score = 0.3·breadth + 0.25·limitup + 0.25·volume + 0.2·volatility；label：<30 冰点 / 30-45 偏弱 / 45-60 中性 / 60-75 偏强 / >75 过热；
- 赚钱效应 = limitup_sub 档位文案；资金面 = volume_sub 档位文案（07 稿三个子项）。
job：并入 poll_market_snapshot（每轮顺算，历史分位查询做 5 分钟缓存）+ 收盘落日频行。
**API**：`GET /v1/market/sentiment` → `{score, label, subs:{...}, money_effect, liquidity, as_of}`。

**验证**：score∈[0,100]；子分可解释（打印各分位输入）。
