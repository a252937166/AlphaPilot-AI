```python
def execute_proposal(session: Session, client: FutuClient, record: TradeProposalRecord) -> BrokerOrder:
    """前置断言（任一不满足抛 ExecutionBlocked，中文 message）：
       settings.paper_trading_enabled and settings.futu_enable_trade
       and not settings.trading_halted and record.status == 'approved'
    1) 幂等：broker_orders 已有该 proposal_id 且状态非 failed → 直接返回既有单
    2) 重跑风控：TradeGuardrails.evaluate(原 proposal, 实时组合状态 fetch_account_funds/positions 换算)
       不过 → record.status='exec_failed'，error=风控理由
    3) 价格：富途快照 last；qty=proposal.quantity 按 100 股取整（A股一手）
    4) trade_call('security','place_order', kwargs={code,price(限价滑点带),qty,trd_side,
       order_type=NORMAL, acc_id}, environment='SIMULATE')   # 绝不传 REAL，绝不带 confirmation
    5) 成功 → BrokerOrder(status=submitted, futu_order_id=...)，record.status='executing'
    """
```

## P2.3-S4 组合快照与收益归因（09 稿四卡数据源） ✅ done 2026-07-22

**models.py**：

```python
class PortfolioSnapshot(Base):
    __tablename__ = "portfolio_snapshots"
    trade_date: Mapped[date] = mapped_column(Date, primary_key=True)
    total_value: Mapped[float]; cash: Mapped[float]
    positions: Mapped[list[Any]] = mapped_column(JSON, default=list)   # [{symbol,qty,mv,industry}]
    daily_return: Mapped[float | None] = mapped_column(Float)
    benchmark_return: Mapped[float | None] = mapped_column(Float)      # SH.000300 当日
    excess_return: Mapped[float | None] = mapped_column(Float)
    drawdown: Mapped[float | None] = mapped_column(Float)              # 净值相对历史峰值
    source: Mapped[str] = mapped_column(String(16), default="futu-sim")
```

**job** `snapshot_portfolio`（cron 交易日 15:10）：fetch_account_funds + positions → 写当日行；daily_return = total_value/前日 -1；benchmark 从 daily_bars 的 SH.000300 取；drawdown 由净值序列滚动峰值算。持仓行业从 securities.industry_csrc 联出（donut 用）。
**API**：
- `GET /v1/portfolio/overview` → 最新快照 + 行业分布（05 稿 donut：总市值、行业占比）；
- `GET /v1/portfolio/attribution?days=60` → `{dates[], nav[], benchmark_nav[], excess_cum, max_drawdown, benchmark_drawdown}`（09 稿"收益归因/风险控制"两卡 + 净值对比图）。

**验证**：连续两个交易日后 daily_return 与富途 App 模拟账户涨跌一致（±0.1pp）；归因接口序列长度=天数。

> ⚠ DEVIATION: 既有 `sync_daily_bars` 在 18:40 执行且只同步证券池，不能保证
> `SH.000300`；通用 `save_bars` 又是 insert-only，同日早盘写入的指数行不会自动修正为
> 完整收盘数据。为避免把盘中 K 线冒充基准，本步把快照时点固定为交易日 15:10，任务先用
> Futu 交易日历 fail closed，再按精确日期拉取 `SH.000300` 完整日线并受控 upsert；另注册
> 19:00 `reconcile_portfolio_benchmark` 对账任务，修正基准后级联重算收益。两项任务均由
> `paper_trading_enabled` 控制，周末和节假日由真实交易日历跳过。

> ⚠ DEVIATION: 当前数据库在本步上线前没有任何真实组合快照，不能伪造两日或 60 日净值。
> `/overview` 与 `/attribution` 因此在首个收盘前返回稳定 200 空态；`days=60` 表示最多返回
> 60 个已真实累积的交易日，缺少精确日期基准时对应 `benchmark_nav` 保留 `null`，绝不拿
