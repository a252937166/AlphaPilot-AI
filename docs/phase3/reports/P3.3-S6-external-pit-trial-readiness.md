## 固定路由与口径

| 数据 | 外部路由 | 对拍字段与口径 |
|---|---|---|
| 日线 / 复权 | 沪深优先 Futu 原始 DAY + HFQ DAY；北交所或 Futu 不可用时走 Sina | close；复权先按 `HFQ/raw` 算目标日与锚点日的相对比，再乘 manifest 冻结的本地锚点因子 |
| 历史估值 | Eastmoney `stock_value_em`，显式 `trust_env=false` 直连 | pe_ttm、pb_mrq、ps_ttm |
| 财务 | Eastmoney F10 | 单个抽样 metric、公告可见时间；仅使用已审计为同定义的 `ROEJQ`、`PARENTNETPROFITTZ`、`NCO_NETPROFIT`、`ZCFZL` |

日线 manifest 为每个样本新增 `adj_anchor_date` 与 `adj_anchor_factor`。锚点取同一股票、严格晚于
目标日的最新审计日线/复权共同日期。这样只比较两源的相对复权变化，不直接比较不同数据源任意
归一化基准的绝对 HFQ 倍数。`NCO_NETPROFIT` 已是比例值，不再除以 100；其余上述东财指标是
百分点，除以 100 后与 AlphaPilot 比较。东财 `TOTALOPERATEREVETZ` / Tushare `or_yoy` 与
本地 `derived.profit.MBRevenue_yoy` 的“主营业务收入同比”定义不完全相同，代码已 fail closed；
若抽中 `revenue_yoy`，在尚未实现同定义两期重算前只能记为 `unavailable`，不能签认。

`source` / `adj_source` 是已被 manifest SHA-256 冻结的本地来源声明；真正的独立外部来源逐样本
写入 `external_source`。任何数值超容差、外部缺数、来源为空、来源含 BaoStock、manifest 哈希
漂移或请求失败，均 fail-closed。

默认数值容差按“绝对值、相对值取较大者”计算：close `0.01 / 0.01%`、adj_factor
`0.001 / 0.01%`、财务 ratio `0.0001 / 0.1%`、PE/PB/PS `0.01 / 0.01%`。试跑报告逐字段写入
最终实际 tolerance，没有因试跑结果放宽容差或替换样本。
