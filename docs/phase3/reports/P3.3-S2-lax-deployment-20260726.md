## 7. ⚠ DEVIATION：本机 launchd 时区

独立复核发现 Mac 的系统时区是 `America/Los_Angeles`。launchd
`StartCalendarInterval Hour=4` 使用系统本地时间，因此原来的 04:10/04:25/04:40
并不是文档约定的 Asia/Shanghai 时间。

已把阿里云、狗云、LAX 三路回传统一迁移为：

- launchd 分别在每小时的 10/25/40 分唤醒轻量门控。
- `run_shanghai_daily.py` 用 `ZoneInfo("Asia/Shanghai")` 判断；只有达到
  04:10/04:25/04:40 且上海当天尚未成功时才执行真实回传。
- 成功日期用 0600 权限原子写入各自 runtime 目录；同日后续唤醒立即退出。
- 如果 Mac 在目标时刻睡眠，醒来后下一小时会补跑；不受 PDT/PST 切换影响。
- 迁移当天三路均已有真实 exit 0 回传证据，故用 2026-07-26 初始化成功状态。
  三个 LaunchAgent 重新 bootstrap 后 RunAtLoad 均 exit 0、未重复传输。

此修复只改变本机快照回传调度，不调用 BaoStock，不改变三台远端采集 timer。
