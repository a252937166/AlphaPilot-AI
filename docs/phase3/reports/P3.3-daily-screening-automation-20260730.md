# P3.3 每日自动选股恢复报告（2026-07-30）

## 结论

本机预测链已恢复为“盘后数据完成 → 因子/风格输出对账 → 自动生成全市场
Top 50 候选快照”。2026-07-30 首个自动快照已真实落库，下一分钟的自然调度
命中了同一 lineage 的幂等保护，没有生成重复快照。

这项改动只生成研究候选，不会创建提醒、提案、委托或交易。候选排序与概率是
工程验证结果，不构成投资建议，也不能替代 P3.3-S7/S9 尚未完成的样本外验证。

## 实现

- 新增独立 `daily_screening` JobSpec：
  - 研究标的固定为 A 股全市场；
  - `top_n=50`、`sort_by=score`、`horizon_days=20`；
  - 上海时区周一至周六运行；
  - 在预测对账任务的 `07/22/37/52` 分之后延迟 5 分钟，于
    `12/27/42/57` 分运行。
- 只有当当日 `factor_values`、`composite_scores`、`stock_scores`、
  `style_daily` 和对应 JobRun lineage 全部满足输出合同时才保存。
- 计算完成后重新读取 lineage；若盘后输入在计算期间发生变化，丢弃旧结果。
- 幂等键绑定交易日、筛选条件、模型版本、风格来源指纹和因子/风格 JobRun
  lineage；同一 lineage 只保存一个快照，修正后的新 lineage 可以保存新快照。
- 计算、lineage 复核和写入分别使用独立数据库会话，避免 SQLite WAL
  `SQLITE_BUSY_SNAPSHOT`。
- 手工 `/v1/screens/run` 继续可用；自动任务复用同一服务层和持久化协议，
  不做 HTTP 自调用。
- 全站时间显示统一固定为 `Asia/Shanghai`，避免客户端系统处于其他时区时把
  A 股任务时间显示成当地时间。
