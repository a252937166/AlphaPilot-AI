## 0. M2 特有铁律（过拟合是这一步的头号杀手，逐条对照）

M1 的敌人是"算错"，M2 的敌人是"**自欺**"——在 1 年样本上事后挑因子、调权重，几乎必然做出一个
回测好看、实盘打回原形的结果。以下铁律不可破：

1. **样本外验证，铁律中的铁律。** 数据切成 **train 窗（定权重）+ test 窗（验业绩）**，时间严格
   前后隔离。挑因子、定权重**只能用 train 窗**；报告业绩、下结论**只认 test 窗**。任何"在 test
   窗上回头调权重"都是作弊。建议 train:test = 前 70% : 后 30%（约 210 : 91 交易日）。

2. **不 p-hacking（不挑选）。** 禁止"试 50 种权重组合挑最好的报告"。**预先定死一个方法**
   （本文 S3：train 窗 IC_IR 加权），一次成型，不回头调。IC_IR 加权本身自动处理方向和强弱
   （反向因子得负权重、弱因子得小权重），不需要人工挑——这正是它防过拟合的关键。

3. **样本量诚实。** 只有 ~1 年数据（切分后各更短），单因子 IC 的统计效力**很弱**。每个因子必须
   报 IC 的 **t 统计量**；|t|<2 就明说"不显著"，绝不把不显著的当有效。M2 所有结论都是
   **"弱证据、方向性参考"**，不是定论——真正确认需要多年样本（当前数据缺口，诚实标注）。

4. **符号翻转要有经济学理由，不能纯数据挖掘。** 若某因子 IC 显著为负（如动量反向），要区分是
   "**这段是反转市**（经济上可解释，翻转合理）"还是"**因子计算/方向本身有 bug**（应修不应翻）"。
   先查计算是否正确（比如 pe_percentile 是否越低越好、符号有没有搞反），排除 bug 后才谈翻转。

5. **相关因子去冗余。** momentum_20d 与 momentum_60d、pe_percentile 与 pb_percentile 高度相关；
   不去冗余，权重会被一组相关因子主导。M2 要报相关矩阵，对 |corr|>0.8 的因子组做处理
   （保留 IC_IR 更高的、或正交化）。

6. **结论可以是"仍然无效"。** 若 test 窗重构后 composite-v2 仍跑输基准，**如实报告失败**，说明
   这套因子在此市场/样本就是不行，需换因子体系或承认数据限制——**绝不允许继续调参直到好看**。
   诚实的二次失败 > 过拟合的虚假成功。

## P3.2-S3 IC_IR 加权权重重构（train 窗，防过拟合） ✅ done 2026-07-24

**目标**：铁律#1/#2。用**不挑选**的规则化方法在 train 窗重构权重。

**backtest/weights_rebuild.py 契约**：
```python
def train_test_split(session, ratio=0.7) -> tuple[date, date, date, date]:
    """按交易日历切:train=[start, split], test=[split, end]。返回四个日期界。"""

def rebuild_weights(session, train_start, train_end) -> dict:
    """1. all_factors_ic 在 train 窗算每因子 IC_IR(带符号)
    2. 去冗余:|corr|>0.8 组保留 |IC_IR| 最大者(其余权重置0)
    3. 权重 = IC_IR(带符号,反向因子自动负权重) / Σ|IC_IR|  归一
       —— 一次成型,不试多组,不挑选(铁律#2)
    4. 产出 config/factor_weights_v2.yaml,元数据含 train 窗口/生成时间/各因子 IC_IR
    返回 {weights, train_window, factor_ic_ir}"""
```

**权重公式明确**：`w_f = IC_IR_train,f / Σ_k |IC_IR_train,k|`（保留符号 → 反向因子得负权重，
等价自动翻转；弱因子 IC_IR 小 → 权重小）。**这是标准、稳健、无挑选的做法。**

**验证**：生成 factor_weights_v2.yaml，权重和 = ±1 归一，反向因子确为负权重；train 窗元数据完整。
**完成标准**：权重由 train 窗单次算出，无 test 窗信息泄漏（代码审查 + 单测证明 rebuild 只读 train 区间）。

⚠ DEVIATION: 契约示例文字把 train/test 都写成包含同一个 `split` 日期，但 M2 铁律要求时间严格
前后隔离。实现按 301 个交易日的前 210 / 后 91 切为
train `2025-04-28～2026-03-11`、test `2026-03-12～2026-07-23`，两窗不重叠；
没有为了照抄区间表示而让分割日同时进入训练和测试。

- `train_test_split` 固定复用 M1 最近 301 个审计交易日，默认 0.7 向下取 210 日训练、
  余下 91 日测试；单测逐日证明 `train_end < test_start`。
- `rebuild_weights` 只把上述 train 起止日传给 `all_factors_ic(sample_tag="train")` 与
  `factor_correlation`。防泄漏单测设置 test 首日为禁区，捕获的两次研究调用均只读 train；
  代码没有接收 test 指标、收益或回测结果的入口。

  `momentum_60d=-0.23697053`（7 期，t=-0.6270）、
  `volatility_20d=-0.51209303`（8 期，t=-1.4484）、
  `turnover_change_5d=-0.33227581`（8 期，t=-0.9398）；仍全部不显著，但预设方法并未
  事后筛掉或调参。其余 9 个因子因无历史 PIT 横截面保持 null，并按诚实缺失规则权重为 0。
- train 相关性没有 `|corr|>0.8` 组，故 4 个可测因子全部按唯一公式一次成型：
