## 0. 回测铁律（违反 = 回测结果全部作废，比功能 bug 严重得多）

回测最大的风险不是崩溃，是**跑出一个看起来很好、实则错误的结果**，然后据此上实盘亏钱。
以下每一条都是量化界血泪教训，实现时逐条对照：

1. **未来函数（look-ahead bias）零容忍。** 决策日 T 的信号，只能用 `available_time ≤ T` 的
   数据。财务数据必须按 `financial_indicators.available_time` 过滤（不是 `report_period`！报告期
   2025Q1 的数据可能 4 月底才披露，5 月才可用）。价格因子只能用 ≤T 的 K 线。**任何"当时还
   不知道的信息"进入决策 = 致命 bug，回测会虚高。**

2. **决策与成交必须错开。** 用 T 日**收盘后**的数据打分 → 在 **T+1** 成交（按 T+1 开盘价或
   VWAP）。绝不允许"用 T 日收盘价决策、又用 T 日收盘价成交"——那是偷看未来。

3. **复权正确性。** `daily_bars` 存的是**不复权价**（BaoStock adjustflag=3）。除权除息日不复权
   价会假跳空，直接用它算收益是错的。**收益必须用复权价**：`日收益 = close_t·adj_t /
   (close_{t-1}·adj_{t-1}) − 1`。买卖用同一复权口径。这是 S1 先解决的前置。

4. **成交可行性过滤（A 股特有）。** 次日**涨停开盘买不进、跌停开盘卖不出、停牌无法成交**。
   选中的票若 T+1 一字涨停，该笔跳过（不能假装买到）。涨跌停幅度按 `securities.board/is_st`
   判（主板±10/创业科创±20/北证±30/ST±5）。

5. **T+1 制度。** 买入当日不可卖出，最早 T+1（隔日）卖。回测持仓逻辑必须遵守。

6. **交易成本必扣，裸收益不作数。** 佣金（双边，约万 2.5，最低 5 元）+ 印花税（**卖出单边**
   千 1）+ 过户费 + 滑点。任何"未扣成本的收益"不得作为结论；换手越高，成本吃得越狠——这正是
   区分真假 alpha 的关键。

7. **幸存者偏差如实标注。** 当前 `securities` 是**当前存续**的全 A，不含已退市股。历史某日的
   真实股票池应含当日存续+可交易的票（包括后来退市的）。M1 **不具备退市股历史**（P0 数据缺口），
   因此回测**带幸存者偏差，必须在报告里显著标注**，不得宣称无偏。

8. **无拟合泄漏。** M1 的信号是**静态权重**（`config/factor_weights.yaml`），不训练，所以是
   "历史检验"而非"训练-测试"——天然无拟合泄漏。但**为 M2 的 ML walk-forward 预留接口**：
   将来引入训练时，训练窗与测试窗必须严格时间隔离，绝不用全样本拟合再报告。

9. **基准对比是必须项。** 任何策略收益必须同时给出 **vs 沪深300** 和 **vs 等权全市场** 两个
   基准。单独的正收益毫无意义——跑赢基准才是 alpha。

10. **可复现。** 回测入参（信号、区间、成本模型、股票池过滤）落库 `backtest_runs.params`；
    同参数重跑结果一致（无随机，或随机种子入库）。

## 1. 目标与范围

**M1 交付：Point-in-Time 固定信号回测器**，对现有 `composite` 多因子信号做首次严格历史检验。

- **信号来源**：复用 `engines/factors.py` 的打分逻辑，对历史每个 rebalance 日用 PIT 数据重算
  （不是读只有 2 天的 `composite_scores` 表）。
- **回测区间**：受日线覆盖限制，约 2025-05 ~ 2026-07（~300 交易日）。财务因子受 `available_time`
  质量限制，报告里标注。
- **输出**：Rank IC 序列、分层净值、多空组合、换手、夏普/回撤/年化、概率校准；vs 双基准；结论
  "现有因子是否有统计显著的 alpha"。

**M1 不做**（留 M2+）：ML 模型训练与 walk-forward、日内/分钟回测、退市股历史、组合优化器、
实盘对接。M1 只回答"现有信号有没有 alpha"。

**backtest/costs.py 契约**：

@dataclass

    commission_bps: float = 2.5      # 双边佣金 万2.5
    commission_min: float = 5.0      # 单笔最低5元
